# Portfólio Profissional | Arthur Rocha

Portfólio profissional desenvolvido para destacar minha trajetória, habilidades e projetos na área de **Qualidade de Software (QA) e Automação de Testes**, com suporte a múltiplos idiomas (Português e Inglês) a alternância de temas (Claro/Escuro).

--------------------------------------------------------------------------------------------------------------------------------------------
## 🚀 Tecnologias Utilizadas
- **HTML5**
- **Tailwind CSS** (via Play CDN)
- **JavaScript Vanilla** (com lógica de tradução dinâmica e gerenciamento de tema via 'localStorage')
- **AOS (Animate on scroll Library)** para animações de rolagem

--------------------------------------------------------------------------------------------------------------------------------------------
## 📋 Requisitos
Por se tratar de uma aplicação web estática moderna, não é necessário instalar o Node.js, npm ou dependências complexas. Você precisará apenas de:

- Um navegador web moderno (Google Chrome, Firefox, Microsoft Edge, etc.).
- Um editor de código de sua preferência (como **VS Code** ou **Cursor**).
- A extensão **Live Server** instalado no editor (recomendado para visualizar o projeto rodando localmente de forma automática)

## Personalização obrigatória antes de publicar

1. Atualize nome, resumo e trajetória em `src/App.jsx`.
2. Troque os links genéricos do GitHub e LinkedIn pelos seus perfis.
3. Troque `seuemail@exemplo.com` pelo seu e-mail.
4. Atualize os projetos em `src/data.js` com descrições e URLs reais.
5. Revise as tecnologias e níveis em `src/data.js`.
6. Atualize o título e a descrição em `index.html`.

Os projetos e níveis atuais são exemplos editáveis, não declarações de experiência comprovada.
